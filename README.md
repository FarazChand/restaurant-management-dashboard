# Restaurant Website & Admin Dashboard with CMS

## About this project

- this project is going to have frontend restaurant website that allows potential customers of the business to view important information about the business, the menu, and make reservations
- this project will also have an authenticated admin dashboard that allows for the owner, manager and staff to interact with the content of the website - depending on their level of authorization
- more features will be added as needed
